# LastCall

AI-agent marketplace for last-minute offers — businesses text surplus via WhatsApp,
agents price, match and book. Built for the All Things Agentic hackathon (Taskmaster track).

## How it works
1. A business messages its surplus on WhatsApp ("12 salads left, close at 9")
2. An AI agent prices the offer within the owner's rules and publishes it
3. Customer wish lists are matched; push notifications go out via the mobile app
4. A binding booking is taken and both sides get confirmation

## Stack
ADK (Python) · Cloud Run · Gemini on Vertex AI · Firestore · Pub/Sub ·
Cloud Scheduler · Firebase Auth / FCM · Expo (React Native) · WhatsApp Cloud API
